# Frontend Setup and Usage

The frontend is built with React, Vite, Electron, React Router, Vitest, Testing Library, and oxlint.

## First-Time Setup

From the main project folder, move into the frontend folder:

```bash
cd frontend
npm install
npm run dev
http://localhost:5173

npm run electron:dev
npm run test:run
npm test
npm run build
npm run lint
